## Authority map

```text
Hallway  = visual shell
Petals   = protected routing layer

Laptop   = 0root authority
Git      = corpus
Agents   = bounded workers

```

## Boundary rules

1. The laptop is the sole root authority for the private test vacuum.
2. The hallway displays state; it does not grant authority.
3. Petals may evaluate policy, but does not silently discover public peers.
4. Posi is single-user test software, not a public service.
5. Git supplies corpus material; it does not execute the runtime.
6. Agents operate only within declared bounds.
7. Railway may receive an explicitly allowed observation projection only.
8. External network access, public swarm participation, and GPU work are off by default.
9. Any future activation must pass the P12 release lock and produce an audit receipt.

This document records architecture and policy only. It starts no process,
opens no socket, deploys no service, and authorizes no external user.
